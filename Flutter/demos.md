# How to Get and Install the Flutter Sample Browser App

The Flutter Sample Browser App is now available for Android, Web, Windows, iOS, and Linux platforms. You can also explore the source code samples through the [Syncfusion Flutter Examples repository on GitHub](https://github.com/syncfusion/flutter-examples).

> **Note:** The Flutter Sample Browser App is fully compatible with macOS. However, as App Center has been deprecated, new macOS builds are no longer released. You can still [build the app from source](https://github.com/syncfusion/flutter-examples) to run it on macOS.
