# About Syncfusion® Flutter Spark Chart widget

Syncfusion<sup>&reg;</sup> Flutter Spark/Micro charts are lightweight charts, typically drawn without axes or coordinates. They present the general shape of data in a simple and highly condensed way.

## Key features

* Supports four spark chart types: line, area, win-loss, and bar.
* Provides marker support for line and area chart types.
* Supports trackball to display additional information about data points when interacting with the spark charts.
* Supports data labels to display information about data points.
* Supports plot bands to highlight a particular range.
